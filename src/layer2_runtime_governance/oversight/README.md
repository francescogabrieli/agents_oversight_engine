# Dynamic oversight capability

This package owns typed assessment and legacy-checkpoint contracts. Evidence and
trajectory are active raw-fact pillars interpreted by OPA. `operational_risk`
retains its public name for compatibility but is now a shadow consequence/impact
assessment with `decision_influence=false` and `not_applicable` outside governed
external proposals.

New contracts belong in `contracts.py`. New raw facts belong in one focused
signal service. Capability profiles are versioned configuration-as-code; adapters
produce only runtime facts. No risk failure, score, or label can select a runtime
directive.
